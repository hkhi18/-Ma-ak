# منصة «مَعَك» — فعاليات للجميع بلا عوائق
> **المنصة الوطنية لتمكين الأشخاص ذوي الإعاقة من اكتشاف الفعاليات الملائمة لاحتياجاتهم، ومساندة المنظمين في رفع معايير الإتاحة والوصول الشامل.**

---

## 1. نظرة عامة على المشروع
منصة **«مَعَك»** هي تطبيق ويب تفاعلي متكامل مبني باللغة العربية بالكامل وباتجاه من اليمين إلى اليسار (RTL)، مصمم وفق أرقى معايير تجربة المستخدم ومعايير إمكانية الوصول العالمية **WCAG AA**. 

تتميز المنصة بخلو واجهتها التام من أي رموز تعبيرية (Emojis)، واعتمادها الحصري على أيقونات مكتبة **Lucide**، مع التزام صارم بألوان الهوية البصرية المستمدة مباشرة من الشعار:
* **الكحلي الداكن (`#0F1E36`)**: للثقة والوضوح والتباين العالي للنصوص والعناصر الرئيسية.
* **الفيروزي / التيل (`#028090`)**: يمثل **المحور الحركي** ومسارات الكراسي المتحركة والمنحدرات.
* **المرجاني / البرتقالي المحمر (`#F26440`)**: يمثل **المحور السمعي** وأنظمة التضخيم والترجمة.
* **الأرجواني / البنفسجي (`#584B9B`)**: يمثل **المحور البصري** والوصف الصوتي ولوحات برايل.
* **الأصفر الكهرماني (`#EAA812`)**: يمثل **المحور الحسي** والغرف الهادئة وتفادي الضوضاء.
* **الأخضر الزمردي (`#2E8B57`)**: يمثل **لغة الإشارة** والاعتماد الرسمي لتجهيزات الوصول.

## 2. المزايا والقدرات الرئيسية

### أ. تجربة الزائر (المستخدم)
1. **محرك المطابقة الفورية (Personal Match Engine)**: احتساب فوري لـ **«نسبة مناسبة لك»** لكل فعالية وفقاً للاحتياجات المحددة في الملف الشخصي.
2. **محاور الإتاحة الأربعة**:
   * **حركي**: مسارات كراسي متحركة، منحدرات ممهدة، مصاعد واسعة، مواقف سيارات قريبة، دورات مياه مجهزة، مسار خالٍ من السلالم.
   * **سمعي**: مترجم لغة إشارة معتمد، ترجمة نصية فورية مباشرة (Live Captions)، سماعات مساعدة (Hearing Loop)، شاشات تنبيه بصرية.
   * **بصري**: خدمة الوصف الصوتي المباشر، لوحات برايل، لوحات تباين بصري عالٍ، مسارات لمسية، السماح بالكلاب المرشدة.
   * **حسي**: غرفة استراحة هادئة، إضاءة خافتة مريحة، بيئة منخفضة الضوضاء، ساعات زيارة هادئة لتفادي الزحام.
3. **المساعد الذكي للفعالية**: يجيب عن كافة استفسارات الوصول معتمداً حصراً ودقة على بيانات الفعالية المسجلة.
4. **المفضلة والبلاغات والتقييمات**: حفظ الفعاليات، تقييم المحاور الأربعة بعد الحضور، والإبلاغ المباشر عن أي عائق ميداني.

### ب. تجربة المنظم (إدارة الفعاليات)
1. **معالج إنشاء الفعالية**: إدخال البيانات وتحديد التجهيزات الميدانية.
2. **حاسبة درجة الوصول الشاملة (Score Engine)**: احتساب درجة إمكانية الوصول التلقائية (من 100) وتوزيعها على المحاور الأربعة في الوقت الفعلي.
3. **اقتراحات التحسين الذكية**: توصيات مبرمجة بالذكاء الاصطناعي توضح الخطوات الأعلى تأثيراً لرفع درجة الإتاحة.
4. **فحص وتحليل صور المداخل بالذكاء الاصطناعي (Vision AI Inspector)**: رفع صور المداخل والمصاعد والمنحدرات لتحليل مطابقتها الهندسية لكود الوصول الشامل وإصدار تقرير فني فوري.

## 3. المعمارية وحزمة التقنيات (Tech Stack)
* **واجهة المستخدم**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
* **الأيقونات**: Lucide React / Lucide SVG
* **قاعدة البيانات والمصادقة**: Supabase (PostgreSQL 15 + RLS + Storage)
* **الذكاء الاصطناعي**: دوال خادم متوافقة مع OpenAI API و Anthropic API
* **التوافقية**: WCAG 2.1 AA، اتجاه RTL كامل، خط عربي قياسي (IBM Plex Sans Arabic)

## 5. طريقة التشغيل والتثبيت

### تشغيل النموذج التفاعلي المباشر (Standalone Demo)
يمكن فتح ملف `index.html` أو `public/index.html` مباشرة في أي متصفح ويب حديث دون الحاجة لتثبيت أي حزم خارجية.

### تشغيل مشروع Next.js الكامل
1. **تثبيت الاعتماديات**:
   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة**:
   انسخ ملف `.env.example` إلى `.env.local` وضع مفاتيح Supabase و OpenAI:
   ```bash
   cp .env.example .env.local
   ```

3. **تطبيق مخطط قاعدة البيانات في Supabase**:
   انسخ محتويات `supabase/schema.sql` ونفذها في محرر SQL في لوحة تحكم Supabase.

4. **تشغيل الخادم التطويري**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`
